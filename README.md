# Expense Tracker 🐍

A simple yet effective Python-based expense tracker for recording and managing daily expenses.  
Built as a practical project to apply Python fundamentals and create a real-world command-line application.

---

## 🚀 Features

- Add and record daily expenses with names and amounts.
- Automatically calculate total expenses.
- User-friendly command-line interface with clear prompts.
- Handles invalid inputs gracefully using `try-except`.
- Compares total spending with a monthly budget and gives feedback.

---

## 🧠 Concepts Learned & Applied

- Python functions and modular code.
- Loops (`while`) and conditionals.
- Lists and tuples for data storage.
- Error handling (`try-except`).
- User input/output formatting (f-strings).

---

## 🛠️ Technologies Used

- Python 3
- Built-in libraries only (no external dependencies)
